# AI 기반 연구지표 업데이트 관리 서비스

연구기관의 핵심 지표를 관리하고, AI가 감지한 업데이트 후보를 검토·승인할 수 있는 웹 프로토타입입니다.

## 주요 기능

- 대시보드: 최신화 현황, 우선 검토 대상, 갱신 일정 확인
- 지표 목록: 상태 필터와 지표 검색
- 지표 상세: 최신값, 추이, 출처 및 변경 이력 확인
- 업데이트 검토: 기존 값과 감지된 신규 값 비교 및 승인
- 최신 지표 다운로드: 최신 상태의 지표를 CSV로 내려받기
- 원문 보기: 지표별 공식 출처 페이지로 이동

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 `http://127.0.0.1:5173/`을 엽니다.

## 기술 구성

- Vite
- Vanilla JavaScript
- CSS

현재는 더미 데이터를 사용하며, 실제 DB 및 AI 데이터 수집 연동 전 단계의 UI 프로토타입입니다.
